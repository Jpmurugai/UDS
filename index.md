# CAN FD and UDS

A step-by-step learning course for recent graduates, from Classical CAN fundamentals to diagnostic services and a real CAN FD bench.

| Document | Contents |

## Study Order

1. Read the syllabus and prepare the simulation tools.
2. Complete the lessons in sequence, recording practical results.
3. Use the reference document when studying protocol requirements.
4. Move to the isolated hardware bench after the simulation exercises.

Use only a simulator or an authorized isolated training bench. Hardware prices are planning estimates, and the course examples are not production ECU specifications.
